# Contributing to MiMo Smart Contract Explainer

Thank you for your interest in contributing!

## Development Setup

1. **Fork and Clone**
   ```bash
   git clone https://github.com/yourusername/mimo-contract-explainer.git
   cd mimo-contract-explainer
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Set Up Environment**
   ```bash
   cp .env.example .env.local
   # Add your Groq API key
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```

## Code Style

- **TypeScript:** Use strict mode, explicit types
- **React:** Functional components with hooks
- **Tailwind:** Use utility classes, avoid custom CSS
- **Naming:** camelCase for variables/functions, PascalCase for components

## Pull Request Process

1. Update README.md if needed
2. Add tests for new features
3. Ensure all tests pass (`npm test`)
4. Update documentation
5. Create PR with clear description

## Issue Reporting

Use GitHub Issues template:
- Describe the problem
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
