# Project Roadmap

## Phase 1: MVP (Current)
- ✅ Basic contract parsing
- ✅ Risk detection (5 common patterns)
- ✅ AI explanations
- ✅ Results dashboard
- ✅ Export functionality

## Phase 2: Enhanced Analysis (Q3 2026)
- Advanced vulnerability detection (10+ patterns)
- Permission visualization with diagrams
- Contract comparison tool
- User accounts and history
- Custom rule engine

## Phase 3: Enterprise Features (Q4 2026)
- Multi-contract project analysis
- CI/CD integration (GitHub Actions)
- API for programmatic access
- Team collaboration features
- Self-hosted deployment option

## Phase 4: Ecosystem (2027)
- IDE plugins (VS Code, Remix)
- Mobile app (iOS/Android)
- Marketplace for custom analyzers
- Certification program for auditors
